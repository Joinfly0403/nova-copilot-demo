# Nova Copilot — AI Agent 悬浮窗 Demo

一个**零依赖、开箱即跑**的 Web Demo，用来演示"成熟的 AI Agent 悬浮窗"应该长什么样：多态窗口、流式对话、工具调用链、人类审批、生成式 UI、上下文注入与状态持久化。

- 🖥️ 在线体验：**https://joinfly0403.github.io/nova-copilot-demo/**
- 默认**浅色主题**（可在设置里切深色，或加 `?theme=dark`）
- 纯静态：解压后直接双击 `index.html` 即可运行

## 运行

```bash
# 方式一：直接双击 index.html

# 方式二：任意静态服务
npx serve .
# 或
python -m http.server 8080
```

## 一分钟体验路线

1. 首次打开会自动展开浮动面板（也可以点右下角悬浮球 / `Ctrl`+`J`）。
2. 点「归因 W36 以来的收入下滑」→ 看思考态 → 工具调用链 → 指标卡 + 图表 + 结论表格。
3. 输入「帮我生成本周周报并发布」→ 出现**审批卡片**，批准后 Agent 继续执行并回写结果。
4. 生成过程中再发一条消息 → 进入**队列托盘**；点红色按钮 → **中断**，队列保留。
5. 拖动标题栏：停靠 ↔ 浮动，松手自动**吸附边缘**；拖右下角悬浮球可吸附四角。
6. 刷新页面：窗口位置/尺寸/形态、对话、偏好全部**自动恢复**。
7. 按 `Esc` 收起为悬浮球；`Ctrl`+`J` 再次唤起。
8. 左下角 **⚗ Demo** 可切换四种形态、六种场景、桌面/移动端视口、层级可视化。
9. 宽度 < 768px（或 Demo 切移动端）时，面板自动变为**底部工作表（Bottom Sheet）**。

## 功能对照

| 设计要求 | Demo 中的实现 |
| --- | --- |
| 多态布局 | 停靠 / 浮动 / 画中画 / 全屏，标题栏内一键切换 |
| 最小化与气泡 | 折叠为 56px 悬浮球，可拖拽并吸附四角，位置持久化 |
| 状态持久化 | `localStorage` 保存窗口几何、形态、主题、偏好、最多 20 条会话 |
| 富文本流式 | Markdown + 代码高亮 + 逐帧打字机 + 光标，支持中断续写 |
| 多模态输入 | 文件/图片上传（≤5 个、单个 ≤4MB、图片预览）、Web Speech API 语音输入（不支持时降级提示） |
| 消息队列与中断 | 忙碌时自动排队，队列托盘可移除/清空；发送按钮切换为 Stop |
| 页面上下文注入 | 顶部上下文胶囊可展开查看注入的 URL / 身份 / 视口 / KPI / 选中文本，可关闭 |
| 工具调用可视化 | 运行中/成功/失败三态、耗时、参数与返回，可折叠，结束后自动淡出 |
| Human-in-the-Loop | 审批卡片 + 结构化表单（渠道/预算/定向/止损开关），决策回写到对话 |
| 生成式 UI | 指标卡、内联面积图（SVG）、代码 Diff、时间线、数据表格 |
| 快捷操作 | 空态启动器、上下文建议 Chip、"猜你想问" follow-ups、`/` 指令 |
| 智能滚动 | 流式时自动跟随，上滑后暂停并出现"回到底部 + 新消息计数" |
| 消息级操作 | 复制、重新生成、编辑重发、赞/踩、朗读、删除 |
| 响应式 | ≥1024 桌面工作台；<768 底部工作表；<640 单栏 |
| 焦点与层级 | overlay 模式焦点捕获 + `inert` 页面 + Esc 恢复焦点；z-index：页面 0 < 悬浮球 60 < 面板 80 < Toast 120 < Modal 200 |
| 主题 | 默认浅色，可切换深色；首访跟随系统偏好，之后记住选择 |
| 可组合原语 | CSS 变量 + 结构化 block 渲染器（`textSeg / rich / approval`），可单独替换消息渲染 |

## 文件结构

```
index.html          宿主示例页（模拟 NovaMetrics 增长驾驶舱）+ 悬浮窗 DOM 骨架
styles.css          设计令牌、浅/深两套主题、四态布局、生成式 UI、响应式与动效
app.js              状态与持久化、Markdown 渲染、流式模拟、工具/审批编排、
                    拖拽吸附、焦点陷阱、快捷键、Demo 控制
```

## 说明

- 所有数据与"Agent 回复"均为前端模拟，不发起任何网络请求；如需接入真实模型，把 `runTurn()` 中的 `plan()` 换成 SSE 流即可，渲染层无需改动。
- 语音输入依赖浏览器 Web Speech API（Chrome/Edge），不支持时会提示降级。
- 偏好、会话与窗口几何保存在 `localStorage` 的 `nova.copilot.v1` 键；设置里可一键重置。
